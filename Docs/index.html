Scope

This guide describes Refmora Free 1.1.1 and its separate Pro add-on. Automatic payouts, conversions and CSV exports require licensed Pro. Enrollment uses WooCommerce My Account; no standalone registration shortcode is documented. Automatic sending is per approved withdrawal, not an advertised bulk mass-payment dashboard. Provider countries, permissions, funds flows and fees remain subject to PayPal/Stripe rules.

For support, include order/withdrawal reference, environment, safe error code and reproduction steps. Remove contacts and credentials before sharing screenshots or exports.

More payout information: PAYOUTS.md. Product/support: WP Methods.
